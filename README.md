## 🏜️ ABOUT THE GAME

**Broken Horizon** is an investigation-driven open-world action-adventure set across the asphalt highways, desert expanses, and fortified outposts of western Rajasthan. 

When the privatized **Horizon Corridor** transit infrastructure project begins swallowing historic settlements and subterranean water basins, an underground wheelman on the run and an investigative journalist chasing corporate collusion are thrust into a high-stakes conspiracy.

### 🎭 The Operatives

* **01 Arjun Mehta** — *The Wheelman & Fabricator*  
  Former long-haul transporter operating out of Mehta Garage on the Jaipur Bypass. Master fabricator behind the custom 4.0L Turbo Diesel 4×4 Expedition Rig, knowing every subterranean crossing and unmapped route through the Thar.
* **02 Kavya Rathore** — *The Investigative Journalist*  
  Independent reporter tracking political broker Mahesh Khandelwal and Vikram Vardhan’s Vardhan Meridian syndicate across the Horizon Corridor with encrypted telemetry gear and UV forensics.

## 🗺️ WORLD ARCHITECTURE & ROAD NETWORK

* **Playable World Target:** 200 km² initial open-world playable scope.
* **Initial 13 Connected Districts:** Jaipur, Dausa, Sawai Madhopur, Kota, Bundi, Ajmer, Pali, Jodhpur, Jaisalmer, Barmer, Udaipur, Rajsamand, and Sikar.
* **Connected Road Network:** 495 miles of contiguous highway, bypass, desert trails, and off-road expedition routes.
* **Expansion Framework:** Long-term technical architecture engineered to scale towards 41 regional districts.

## ⚡ WEB PORTAL FEATURES

* **Rockstar/Remedy AAA Editorial Aesthetic:** Deep cinematic dark palette, ~80% artwork / 20% typography ratio, and minimal UI chrome.
* **Cinema Showcase District Explorer:** Dynamic 16:9 panoramic district frame with quick-jump navigation across all 13 initial territories.
* **Dual Operative Dossiers:** Instant dossier switching between Arjun Mehta and Kavya Rathore with simulated field telemetry audio intercept.
* **Interactive Mehta Garage Tuning Lab:** 2.5D canvas vehicle schematic, real-time tire pressure and suspension geometry dyno, and procedural Web Audio engine ignition/throttle acoustics.
* **High-Fidelity 16:9 Media Lightbox:** Curated visual concept studies and in-engine pre-alpha renders with fullscreen inspector.
* **Direct Closed Playtest Registry:** Seamless sign-up interface for upcoming community telemetry passes.

## 🚀 GETTING STARTED

### Prerequisites
* Node.js 18+
* npm or pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/shreyansh316/broken-horizon-web.git

# Navigate to project directory
cd broken-horizon-web

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
# Typecheck and build for production
npm run build

# Preview production build locally
npm run preview
```

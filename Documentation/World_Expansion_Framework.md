# BROKEN HORIZON — WORLD EXPANSION FRAMEWORK ARCHITECTURE

## 1. Overview & Core Philosophy

Broken Horizon separates its **initial production roadmap** from its **long-term world expansion vision**:

* **Current Production Target**: **13 districts** across a **200 km²** target playable world centered in Jaipur.
* **Long-Term Vision**: Progressive scaling up to **41 Rajasthan districts** through the dedicated **World Expansion Framework (Phase 51+)**.
* **Progressive Rollout Stages**: `13 → 20 → 30 → 41 Districts`.

> **Transparency Principle**: The website and marketing materials never claim that all 41 districts are immediately playable. Instead, the initial release delivers a dense, high-fidelity 200 km² world (13 districts) with modular architectural hooks that enable adding future districts as content packages rather than requiring game engine or architectural overhauls.

## 3. Phase 51+ World Expansion Framework Specification

Scheduled immediately after the initial Phase 50 production milestone, **Phase 51+** establishes the following modular systems:

1. **District Registry & Modular Packages**: Dynamic registration of territory packages for up to 41 districts without rebuilds.
2. **World Map Expansion System**: Procedural fog-of-war scaling, scalable vector boundaries, and GPS routing across new frontiers.
3. **Road & Route Connection Engine**: Seamless spline network stitching between newly added sectors and existing regional highways.
4. **District Metadata & Settlement Hierarchy**: Structured database for cities, taluks, villages, landmark POIs, and cultural history.
5. **District-Specific Populations & Wildlife**: Demographic distribution systems and regional fauna spawning hooks per biome.
6. **Weather & Environment Profiles**: Localized micro-weather (sandstorms, monsoon flash floods, heat mirages) per district.
7. **Mission & Activity Expansion Hooks**: Dynamic bounty, faction contract, and exploration event generators.
8. **Save Game Compatibility**: Backward-compatible save architecture ensuring player progression persists across newly activated territory packs.
9. **Streaming & Memory Budget Guardrails**: Strict memory and asset streaming budgets ensuring stable 60 FPS performance regardless of active district count.
